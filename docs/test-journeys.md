# 站点用户旅程

1. 作为没有参会的同事，我希望从首页理解知识库用途并进入会议目录，从而快速判断先学什么。
2. 作为寻找特定知识的读者，我希望用自然中文搜索并按标签筛选，从而缩小会议范围；清空条件后恢复全部结果。
3. 作为准备与 AI Agent 对话的读者，我希望阅读单场会议的完整知识结构并一键复制提示词，从而把会议知识带入自己的工作流。
4. 作为按月系统学习的读者，我希望看到按时间组织的学习路径，从而依次完成理解、实践和复盘。
5. 作为键盘、移动设备或 reduced-motion 用户，我希望导航、筛选和复制操作均可访问，页面不会依赖动画才能理解。
6. 作为从 GitHub Pages 项目子路径访问的读者，我希望所有链接和资源保持在项目基路径内，不出现根路径跳转或资源 404。
7. 作为没有参加整月会议的读者，我希望阅读跨会议的月度洞察、回到所有关联会议核对，并复制综合 Agent Prompt；若尚无综合内容，也能看到清楚且可继续导航的空态。
8. 作为核对资料完整性的读者，我希望看到可访问妙记、公开页、内容状态和无产物会议的聚合台账，从而知道哪些结论可用、哪些内容没有证据且未被补写。

## 自动化验收

- 单元：内容校验/排序、综合洞察结构与关联断链、私有字段拦截、统计、学习路径、搜索、标签与子路径拼接。
- 集成：fixture JSON 经真实文件系统加载后形成页面所需数据。
- E2E：首页到目录、搜索和标签组合、详情阅读与复制、月度路径、覆盖台账、404、移动端导航、键盘焦点、reduced-motion。
